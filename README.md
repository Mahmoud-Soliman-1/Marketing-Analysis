# Marketing Analysis Project

## Project Overview
This project demonstrates an end-to-end marketing data analysis workflow using **SQL, Python, and Power BI**. The goal is to extract, process, and visualize marketing data to gain actionable insights into **customer feedback, conversion trends, social media performance, and product ratings**. The analysis helps identify business challenges and opportunities, enabling data-driven decision-making to optimize marketing strategies and enhance customer engagement.
You can also watch the video titled [**Presentation Insights and Recommendation**]([https://example.com](https://github.com/Mahmoud-Soliman-1/Marketing-Analysis/blob/main/Presentation%20Insights%20and%20Recommendation.m4v)) for a more detailed analysis, including insights and recommendations from the data.


## Business Problems Addressed
- Limited visibility into marketing campaign performance and ROI.  
- Difficulty in interpreting customer feedback across multiple channels.  
- Need for a unified dashboard to track key metrics and support strategic decisions.  
- Lack of actionable insights from scattered raw data.

## Technologies Used
- **SQL**: Data extraction, transformation, and aggregation; calculated metrics such as average ratings and conversion metrics.  
- **Python**: Sentiment analysis to classify customer reviews and feedback as positive, negative, or neutral.  
- **Power BI**: Creation of interactive dashboards for visualizing KPIs and trends effectively.

## Project Workflow
1. **Data Extraction & Transformation (SQL)**  
   - Pull data from multiple tables and sources.  
   - Clean and filter data to ensure accuracy.  
   - Generate calculated fields for metrics like average ratings and conversion rates.

2. **Sentiment Analysis (Python)**  
   - Analyze textual customer reviews.  
   - Classify feedback to extract actionable insights about customer satisfaction.

3. **Visualization (Power BI)**  
   - **Overview Dashboard**: High-level summary of marketing KPIs.  
   - **Conversion Details**: Track conversion rates and trends over time.  
   - **Social Media Insights**: Monitor engagement and campaign impact.  
   - **Rating Details**: Visualize average ratings and customer sentiment.

## Key Learnings & Outcomes
- Integrated multiple data sources into a coherent analytical pipeline.  
- Applied sentiment analysis to uncover meaningful insights from customer feedback.  
- Developed interactive dashboards to communicate insights effectively to stakeholders.  
- Highlighted key marketing KPIs and trends to support data-driven decisions.
